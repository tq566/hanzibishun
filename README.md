# 汉字笔顺

#### 介绍
帮助用户准确掌握每个汉字的标准笔画顺序和正确书写方法。具体功能要求如下：

1.  支持用户手动输入任意中文汉字，支持批量输入多个汉字，输入框需具备实时输入校验，仅允许输入有效中文汉字，自动过滤非汉字字符

2.  针对用户输入的每个汉字，严格遵循国家语言文字工作委员会发布的《现代汉语通用字笔顺规范》，完整展示标准的动态笔画书写过程
